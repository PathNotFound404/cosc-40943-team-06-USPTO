USPTO Patent Intelligence 1.1.0 adds a Windows installer. The macOS app is unchanged from 1.0.0 apart from the version number.

**What's new**

- A Windows installer for 64-bit Windows 10 and 11. It installs for your account only, with no administrator password, and adds a Start menu shortcut and an uninstaller.
- On Windows, imported data is kept in `%LOCALAPPDATA%\USPTO Patent Intelligence`, separate from the app, so updating or uninstalling the app never deletes it.

**Install**

- **Mac** (Apple silicon, macOS 15 Sequoia or later): download `USPTO-Patent-Intelligence-1.1.0-arm64.dmg` below, open it, and drag the app into Applications, choosing **Replace** if 1.0.0 is installed. Your imported data is kept.
- **Windows:** download `USPTO-Patent-Intelligence-1.1.0-x64-setup.exe` below and run it. The installer is not signed, so if Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.

The [user guide](https://github.com/PathNotFound404/cosc-40943-team-06-USPTO/blob/main/docs/user-guide.md) walks through both.
